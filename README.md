# 90-day onboarding

Living 90-day onboarding and execution plans for new Localytics engineering hires.

This is a documentation repo. It is not an application. The plan in `docs/` is the working copy used during onboarding. Hiring drafts and interview artifacts stay in the interviews repo.

| ---------------- | ---- | ------------ | ------------------------------------------ |
| Juan Jose Iguaran Fernandez | Machine Learning Engineer | Sep 21, 2026 | [docs/90-day-plan.md](docs/90-day-plan.md) |


Read the plan first. It is the source of truth for goals, week-by-week deliverables, and the day-90 definition of success.

## Layout

```
README.md                 This file
AGENTS.md                 Instructions for assistants editing this repo
docs/90-day-plan.md       Current hire's 90-day plan
docs/meeting-logs.md      Onboarding meeting notes (newest first)
```



## What belongs here

- The hire-facing 90-day plan: welcome, who to go to, operating expectations, timeline, deliverables, success criteria.
- Small updates to that plan as onboarding progresses (dates, owners, links to shipped work).
- Onboarding meeting logs in `docs/meeting-logs.md`. Newest entry goes at the top.



## What does not belong here

- Product requirements, application code, or infrastructure. Link out to the PRD or repo instead of copying it in.
- Secrets, credentials, or customer PII.

Agent instructions for editing this repo: [AGENTS.md](AGENTS.md).
